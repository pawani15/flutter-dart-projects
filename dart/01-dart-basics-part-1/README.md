# Dart Basics – Part 1

## Objective
Learn fundamental Dart programming concepts and develop problem-solving skills.

## Topics Covered
- Variables and Data Types
- Arithmetic, Relational and Logical Operators
- Conditional Statements (if, else, switch)
- Loops (for, while, do-while)
- Input and Output
- Number Series and Mathematical Problems

## Programs
1. Variables and Data Types
2. Operators
3. Conditional Statements
4. Loops
5. Input and Output
6. Number Series and Sums

## How to Run

```bash
dart run 01_variables.dart
dart run 02_operators.dart
dart run 03_conditions.dart
dart run 04_loops.dart
dart run 05_input_output.dart
dart run 06_number_series.dart
```

## Result
Implemented and tested Dart programs covering fundamental programming concepts.
