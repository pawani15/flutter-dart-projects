# Dart Basics – Part 2

## Objective
Understand advanced Dart programming concepts and practice writing reusable, structured code.

## Topics Covered
- Functions and Return Types
- Lists, Sets and Maps
- String Manipulation
- Object-Oriented Programming
- Classes and Objects

## Programs
1. User-Defined Functions
2. List, Set and Map Operations
3. String Manipulation
4. Classes and Objects

## How to Run

```bash
dart run 01_functions.dart
dart run 02_lists_sets_maps.dart
dart run 03_strings.dart
dart run 04_oop.dart
```

## Result
Implemented Dart programs demonstrating functions, collections, string operations and object-oriented programming.
