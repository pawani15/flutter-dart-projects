# Flutter Project Creation and Customization 🚀

## Objective
Create a Flutter project, understand its structure, customize the application title and home screen, and run the application.

## Requirements
- Create a new Flutter project.
- Understand the default project structure.
- Modify main.dart.
- Change the application title.
- Create a custom home screen.
- Run on Android Emulator.

## Widgets Used
- MaterialApp
- Scaffold
- AppBar
- Text
- Icon
- Column
- ElevatedButton

## Commands

```bash
flutter create flutter_custom_app
cd flutter_custom_app
flutter pub get
flutter analyze
flutter run
```
