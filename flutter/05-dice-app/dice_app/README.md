# Dice App 🎲

## Objective
Develop a Flutter Dice App that displays a dice and generates a new random dice value whenever the user presses the Roll Dice button.

## Requirements Completed
- Display a dice face.
- Implement a Roll Dice button.
- Generate random numbers from 1 to 6.
- Update dice faces dynamically.
- Use StatefulWidget.
- Use setState() for UI updates.
- Ensure the dice value changes on every button press.

## Flutter Concepts Used
- StatefulWidget
- setState()
- Random number generation
- StatelessWidget
- MaterialApp
- Scaffold
- Column and Row
- ElevatedButton
- BoxDecoration
